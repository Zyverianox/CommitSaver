# CommitSaver
#### Saves your commits so nobody can criticize you for having 1,000 commits on your repository, or 500 like I do.
#### You can use this by forking or downloading here. When you get the zip, extract it and delete the README.md. When you finished extracting the zip file, add your files inside the folder.
#### You can add one if you want, like your class1.cs file, for example. If you already have a repository (if you haven't made one, do so), you can make it private or public (privating is recommended).
#### Then, find the button called "Add file..." and press it. Select "Upload File" and choose a file inside the folder that you like to upload. After that wait and that's it, you're finished. 
#### You should have less commits then before. Your welcome.
